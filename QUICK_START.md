# 🚀 Quick Start - Admin Panel

## ⚡ 3-Step Setup

### Step 1: Create Admin User
```bash
cd backend
node seedAdmin.js
```

### Step 2: Start Backend
```bash
cd backend
npm start
```
✅ Backend running on http://localhost:5000

### Step 3: Start Frontend
```bash
npm start
```
✅ Frontend running on http://localhost:3000

## 📊 Admin Panel Sections

| Section | Features |
|---------|----------|
| **Dashboard** | Stats, Recent Orders, Low Stock |
| **Products** | View, Edit, Delete Products |
| **Add Product** | Create New Products |
| **Orders** | View, Update Order Status |
| **Users** | View, Promote, Delete Users |

---

## 🔧 Common Tasks

### Add a Product
1. Go to "Add Product"
2. Fill in details
3. Click "Create Product"

### Update Order Status
1. Go to "Orders"
2. Click "View" on order
3. Select new status
4. Status updates automatically

### Make User Admin
1. Go to "Users"
2. Find user
3. Click "Make Admin"
